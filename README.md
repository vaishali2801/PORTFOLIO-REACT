# Vaishali Chauhan | React Portfolio

A personal portfolio website built with **React.js, Vite, Bootstrap, and CSS** to showcase my profile, technical skills, education, and web development projects.
##screenshot


## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Navigation bar with smooth section navigation
- Hero section introducing me as a Frontend Developer
- About Me section
- Technical skills showcase
- Featured projects with live demo and GitHub links
- Education and learning journey
- Contact section with email integration
- Resume access
- Reusable React components
- Modern dark theme with accent colors

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript (ES6+)
- **Build Tool:** Vite
- **Styling:** CSS3, Bootstrap 5
- **Icons:** Bootstrap Icons
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/vaishali2801/My-Portfolio.git
```

If you created a separate GitHub repository for the React version, replace the URL above with that repository's URL.

### 2. Navigate to the project directory

```bash
cd my-portfolio-react
```

### 3. Install dependencies

```bash
npm install
npm install bootstrap bootstrap-icons
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the portfolio.

### 5. Create a production build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 💻 Customization

Update `src/data/portfolioData.js` to change:

- Personal information and introduction
- Technical skills
- Project details, technologies, and links
- Education details
- GitHub, LinkedIn, email, and resume links

Update `src/index.css` to customize the colors, layout, typography, and responsive styling.

Place profile images and other static assets in the `public/img/` directory.
